# Project status

Copy this to `STATUS.md` in the linked project workspace. Replace prompts with sourced facts, omit empty sections, and keep it short.

**Last updated:** YYYY-MM-DD (informational edit date; include time and timezone when needed).

## Current state

State what exists, what changed, and any blocker, with observation dates and supporting links. Keep proposed, agreed, implemented, adopted, and measured outcomes distinct.

## Decision log

Record recent material decisions, newest first: date, decision, decision-maker when known, and evidence. Label proposals clearly. Link a longer decision history if one already exists.

## Commitments

Record each material commitment's outcome, owner, and agreed date or explicit unknown. Identify proposed ownership or dates. Link canonical Jira or Confluence records for shared commitments when present.

Include adoption checks, impact measurement, and communication commitments for shipped work, each with an owner and date or explicit unknown.

## Open questions

Record unresolved questions and what would settle them.

## Workspace instruction

Add this sentence to the workspace's own AGENTS.md or CLAUDE.md:

> Before completing or handing off work that changes state, decisions, or commitments, update STATUS.md.
