# Personal context

Copy this to ignored `self.md` at the repository root. Replace prompts with supplied facts; omit sections you do not need. This template contains no current role or employer assumptions.

## Role and mandate

What are you accountable for? What decisions can you make, and which require agreement? Record the source and date for formal boundaries.

## Current priorities

Link the local priorities and project records you want the adviser to use. Describe what success would change, rather than listing activity.

## Working preferences

What kind of challenge is useful? How do you like to think aloud? Include a short example of advice or writing that sounds right to you. The shared default is thoughtful, direct, personal, and willing to disagree.

## Development and review context

Add enduring development themes or performance context only when you want them used. Keep evidence separate from interpretation. This file stays local.
